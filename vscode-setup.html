เมื่อเราติดตั้ง VS Code และ Compiler (g++) เรียบร้อยแล้ว ขั้นตอนต่อไปคือการบอกให้ VS Code รู้จักกับ C++ และตั้งค่าปุ่มลัดสำหรับการ Compile และ Run โค้ด

1. ติดตั้งส่วนขยายที่จำเป็น (Extensions)

ส่วนขยาย (Extensions) ใน VS Code จะช่วยเพิ่มความสามารถในการเขียน, ตรวจสอบ, และ Debug โค้ด C++ ได้ดีขึ้นมาก

เปิด VS Code

ไปที่ Extensions

คลิกไอคอนสี่เหลี่ยมซ้อนกันทางซ้ายมือ หรือกด Ctrl+Shift+X

🔍 ค้นหาและติดตั้ง 2 ส่วนขยายหลักนี้:

ส่วนขยาย ผู้พัฒนา หน้าที่สำคัญ
C/C++ Extension Pack Microsoft ให้ฟีเจอร์พื้นฐานสำหรับ C++ เช่น การเติมโค้ดอัตโนมัติ (IntelliSense) และการ Debug
Code Runner Jun Han ช่วยให้สามารถ Run โค้ดได้อย่างรวดเร็วด้วยปุ่มเดียว (โดยเฉพาะสำหรับไฟล์เดียว)

💡 เคล็ดลับ: C/C++ Extension Pack นั้นสำคัญที่สุดสำหรับการทำงานอย่างมืออาชีพ

2. การ Compile และ Run โค้ดแบบง่าย (โดย Code Runner)

สำหรับนักเรียน สอวน. ในค่าย 1 โจทย์ส่วนใหญ่จะอยู่ในรูปแบบ Single File (ไฟล์เดียวจบ) ซึ่ง Code Runner จะช่วยให้คุณ Run โค้ดได้ง่ายที่สุด

📝 สร้างไฟล์ทดสอบ

สร้างไฟล์ใหม่ใน VS Code (เช่น test.cpp) แล้วเขียนโค้ด C++ ง่าย ๆ ลงไป:

#include <iostream> int main() { std::cout << "Hello, OSN Camp 1!" << std::endl; return 0; }

🏃‍♂️ วิธี Run โค้ด

▶️ วิธีที่ 1: ใช้ปุ่ม Run

กดปุ่ม สามเหลี่ยม (Run) ที่มุมขวาบนของ Editor

⌨️ วิธีที่ 2: ใช้คีย์ลัด

Windows/Linux: Ctrl+Alt+N
macOS: Ctrl+Option+N

✅ ผลลัพธ์: ผลลัพธ์ของโปรแกรมจะแสดงในหน้าต่าง OUTPUT หรือ TERMINAL ของ VS Code

3. การตั้งค่า Debugging ขั้นสูง (ด้วย C/C++ Extension)

ในการแก้ปัญหาที่ซับซ้อน เราจำเป็นต้องใช้ Debugger เพื่อดูค่าตัวแปรในแต่ละขั้นตอน ซึ่งเป็นทักษะสำคัญที่ต้องฝึกฝน

เมื่อคุณต้องการ Debug โปรแกรม คุณต้องสร้างไฟล์การตั้งค่า 2 ไฟล์ คือ tasks.json และ launch.json โดยปกติแล้ว VS Code จะช่วยสร้างไฟล์พื้นฐานให้คุณ

🐛 ขั้นตอนการ Debugging:

  1. เปิดไฟล์ C++ ที่ต้องการ Debug (เช่น program.cpp)
  2. ไปที่แถบ Run and Debug (ไอคอนแมลงทางซ้ายมือ) หรือกด Ctrl+Shift+D
  3. คลิก "Run and Debug"
  4. VS Code จะถามหา Environment ให้เลือก "C++ (GDB/LLDB)" (สำหรับ MinGW/GCC)
  5. VS Code จะสร้างไฟล์ launch.json และ tasks.json ในโฟลเดอร์ .vscode ของโปรเจกต์คุณ

⚠️ สำคัญ: ตรวจสอบในไฟล์ launch.json ว่าพารามิเตอร์ program ชี้ไปยังไฟล์ Output ที่ถูกต้อง (มักจะชื่อ a.exe หรือ %workspaceFolder%\a.exe) และ miDebuggerPath ชี้ไปยัง gdb.exe ของคุณ

4. โครงสร้างไฟล์โปรเจกต์สำหรับค่าย

แม้ว่าเราจะใช้ Code Runner ในการฝึกฝน แต่ในการจัดเก็บงานควรจัดให้อยู่ในโครงสร้างที่เป็นระเบียบ:

/OSN_CAMP1_PREP /Day1 /Ex_A_IfElse Ex_A_IfElse.cpp /Ex_B_Loop Ex_B_Loop.cpp /Day2 /Vector_Basic Vector_Basic.cpp

💡 ข้อแนะนำ: การจัดระเบียบไฟล์ตั้งแต่เริ่มต้นจะช่วยให้คุณหาโค้ดเก่าได้ง่ายเมื่อต้องใช้อ้างอิง
