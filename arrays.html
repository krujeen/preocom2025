🎯 อาร์เรย์คืออะไร?

อาร์เรย์ (Array) คือโครงสร้างข้อมูลที่ใช้จัดเก็บชุดของข้อมูลที่มี ชนิดข้อมูลเดียวกัน โดยเก็บต่อเนื่องกันในหน่วยความจำ ซึ่งช่วยให้เข้าถึงข้อมูลได้อย่างรวดเร็วผ่านการใช้ ดัชนี (Index)

1. การประกาศและเริ่มต้นใช้งานอาร์เรย์

การประกาศอาร์เรย์ต้องระบุชนิดข้อมูลและขนาด (จำนวนสมาชิก) ที่แน่นอนไว้ล่วงหน้า

📋1.1 การประกาศอาร์เรย์ 1 มิติ (One-Dimensional Array)

🔢การประกาศอาร์เรย์จำนวนเต็ม
Integer Array 💻 C++
// ชนิดข้อมูล ชื่ออาร์เรย์[ขนาด]; int scores[10]; // อาร์เรย์ชื่อ 'scores' เก็บตัวเลขจำนวนเต็มได้ 10 ตัว
💰การประกาศอาร์เรย์ทศนิยม
Double Array 💻 C++
double prices[5]; // อาร์เรย์ชื่อ 'prices' เก็บเลขทศนิยมได้ 5 ตัว

⚡1.2 การกำหนดค่าเริ่มต้น (Initialization)

คุณสามารถกำหนดค่าเริ่มต้นให้กับอาร์เรย์ได้ทันทีที่ประกาศ

Array Initialization 💻 C++
// กำหนดค่าเริ่มต้นให้กับสมาชิกทั้งหมด int numbers[5] = {10, 20, 30, 40, 50}; // ถ้ากำหนดค่าน้อยกว่าขนาดที่ประกาศไว้ สมาชิกที่เหลือจะถูกกำหนดเป็น 0 โดยอัตโนมัติ int small_array[10] = {1, 2, 3}; // สมาชิกที่เหลือ 7 ตัวจะเป็น 0
2. การเข้าถึงสมาชิก (Accessing Elements)

สมาชิกแต่ละตัวในอาร์เรย์จะถูกเข้าถึงโดยใช้ ดัชนี (Index) โดย ดัชนีจะเริ่มจาก 0 เสมอ

ถ้าอาร์เรย์มีขนาด N ตัว ดัชนีที่ถูกต้องจะอยู่ในช่วง [0,N−1]

อาร์เรย์ A[0] A[1] A[2] … A[N−1]
ตำแหน่ง สมาชิกตัวแรก สมาชิกตัวที่สอง สมาชิกตัวที่สาม … สมาชิกตัวสุดท้าย

🎯ตัวอย่าง: การกำหนดค่าและเข้าถึงสมาชิก

Array Access 💻 C++
#include <iostream> using namespace std; int main() { int data[4]; // อาร์เรย์ขนาด 4 (ดัชนี 0, 1, 2, 3) data[0] = 5; // กำหนดค่า 5 ให้สมาชิกตัวแรก data[3] = 99; // กำหนดค่า 99 ให้สมาชิกตัวสุดท้าย cout << "Value at Index 0: " << data[0] << endl; cout << "Value at Index 3: " << data[3] << endl; // การเข้าถึงดัชนีที่เกินขอบเขต (เช่น data[4]) จะทำให้เกิดข้อผิดพลาด (Undefined Behavior) return 0; }
Value at Index 0: 5 Value at Index 3: 99
3. การใช้งานร่วมกับ Loop

การวนซ้ำเป็นวิธีเดียวที่จะช่วยให้เราประมวลผลสมาชิกทุกตัวในอาร์เรย์ได้อย่างมีประสิทธิภาพ

🔄ตัวอย่าง: รับค่าเข้าอาร์เรย์ และแสดงผลรวม

Array with Loop 💻 C++
#include <iostream> using namespace std; int main() { const int SIZE = 5; // ใช้ const เพื่อกำหนดขนาดให้ชัดเจน int numbers[SIZE]; int sum = 0; // ส่วนที่ 1: รับค่าเข้าอาร์เรย์ โดยใช้ for loop วนตามดัชนี 0 ถึง SIZE-1 cout << "Enter 5 numbers:" << endl; for (int i = 0; i < SIZE; i++) { cout << "Number " << i + 1 << ": "; cin >> numbers[i]; // รับค่าเข้าสู่ดัชนีที่ i } // ส่วนที่ 2: ประมวลผลและคำนวณผลรวม cout << "\nNumbers entered: "; for (int i = 0; i < SIZE; i++) { cout << numbers[i] << " "; sum += numbers[i]; // บวกค่าที่ดัชนีที่ i เข้าไปใน sum } cout << "\nTotal Sum: " << sum << endl; return 0; }
Enter 5 numbers: Number 1: 10 Number 2: 20 Number 3: 15 Number 4: 25 Number 5: 30 Numbers entered: 10 20 15 25 30 Total Sum: 100
4. อาร์เรย์ 2 มิติ (Two-Dimensional Array)

อาร์เรย์ 2 มิติใช้สำหรับจัดเก็บข้อมูลในรูปแบบตาราง (แถวและคอลัมน์) เหมือนกับเมทริกซ์

📊4.1 การประกาศอาร์เรย์ 2 มิติ

2D Array Declaration 💻 C++
// ชนิดข้อมูล ชื่ออาร์เรย์[จำนวนแถว][จำนวนคอลัมน์]; int matrix[3][4]; // อาร์เรย์ 3 แถว 4 คอลัมน์ (รวม 12 ช่อง)

📋 การจัดเรียงข้อมูลในอาร์เรย์ 2 มิติ

1
2
3
4
5
6

แถวที่ 0: [1, 2, 3] | แถวที่ 1: [4, 5, 6]

🔄4.2 การเข้าถึงและใช้งาน Loop ซ้อนกัน

ต้องใช้ Nested Loop ในการประมวลผลข้อมูลในอาร์เรย์ 2 มิติ โดย Outer Loop มักจะควบคุม แถว และ Inner Loop ควบคุม คอลัมน์

2D Array with Nested Loops 💻 C++
#include <iostream> using namespace std; int main() { int matrix[2][3] = { // 2 แถว, 3 คอลัมน์ {1, 2, 3}, // แถวที่ 0 {4, 5, 6} // แถวที่ 1 }; // การเข้าถึง: matrix[แถว][คอลัมน์] cout << "Element at [1][2]: " << matrix[1][2] << endl; // ผลลัพธ์: 6 // การวนซ้ำเพื่อพิมพ์ค่าทั้งหมด for (int row = 0; row < 2; row++) { for (int col = 0; col < 3; col++) { cout << matrix[row][col] << "\t"; // พิมพ์ค่าในแถวปัจจุบัน } cout << endl; // ขึ้นบรรทัดใหม่เมื่อจบรอบของแถว } return 0; }
Element at [1][2]: 6 1 2 3 4 5 6

⚠️สรุปข้อควรระวังสำหรับอาร์เรย์

  • ขนาดคงที่ (Fixed Size): เมื่อประกาศขนาดแล้ว ไม่สามารถเปลี่ยนแปลงได้ (นี่คือข้อจำกัดใหญ่ที่ทำให้เราต้องใช้ Vector ในชั่วโมงที่ 9)
  • ดัชนีเริ่มต้นจาก 0: นี่คือจุดที่นักเรียนทำผิดพลาดบ่อยที่สุด! โปรดจำไว้ว่าสมาชิกตัวแรกคือ Array[0] เสมอ
  • ระวังการเข้าถึงนอกขอบเขต (Out-of-Bounds Access): การพยายามเข้าถึงดัชนีที่ไม่มีอยู่ (เช่น A[N] ในอาร์เรย์ขนาด N) จะทำให้เกิดข้อผิดพลาดร้ายแรงในโปรแกรม

🏋️ โจทย์ฝึกหัด

🎯 โจทย์: ค้นหาค่าสูงสุดในอาร์เรย์

จงเขียนโปรแกรมที่รับตัวเลข 10 ตัว มาเก็บในอาร์เรย์ แล้วค้นหาว่า ตัวเลขที่มีค่าสูงสุด ในอาร์เรย์นั้นคืออะไร

💡 คำใบ้:

  • ใช้ตัวแปรเก็บค่าสูงสุดที่พบจนถึงขณะนั้น
  • วนลูปเปรียบเทียบแต่ละสมาชิกกับค่าสูงสุดปัจจุบัน
  • อัปเดตค่าสูงสุดเมื่อพบค่าที่มากกว่า

🎯 ขั้นตอนต่อไป

โครงสร้างข้อมูลอาร์เรย์มีความสำคัญมาก แต่ในการแข่งขันจริง เรามักจะใช้ Vector ซึ่งเป็นญาติที่ยืดหยุ่นกว่าของอาร์เรย์ ซึ่งเราจะพูดถึงในชั่วโมงถัดไป
