โจทย์ที่ 1: การจัดการคะแนนเฉลี่ย

Vector & Function

📋 โจทย์:

จงเขียนโปรแกรมที่รับจำนวนนักเรียน N (โดยที่ 1≤N≤100) จากนั้นรับคะแนนของนักเรียนทั้ง N คน เก็บไว้ใน std::vector และทำการแสดงผลลัพธ์ดังนี้:

  1. คำนวณและแสดงผล คะแนนเฉลี่ย (Average Score) ของนักเรียนทั้งหมด
  2. หาและแสดงผล คะแนนสูงสุด (Maximum Score)
  3. นับและแสดงผลจำนวนนักเรียนที่ได้คะแนน มากกว่าหรือเท่ากับ คะแนนเฉลี่ย

🧠แนวคิดการแก้ปัญหา (Think before Code!)

Input

รับ N จากนั้นใช้ for loop วนซ้ำ N รอบเพื่อรับคะแนนแต่ละคน

Storage

ใช้ std::vector<int> ในการเก็บคะแนน

Function

ควรสร้างฟังก์ชันย่อยอย่างน้อย 2 ฟังก์ชันเพื่อจัดระเบียบโค้ด

Complexity

ปัญหานี้ต้องวนซ้ำ Vector 1-2 รอบ ดังนั้น Time Complexity คือ O(N)

🔧 ฟังก์ชันที่แนะนำ:
  • double calculateAverage(const vector<int>& scores)
  • int findMax(const vector<int>& scores)
⚡การวิเคราะห์ Complexity:

ปัญหานี้ต้องวนซ้ำ Vector 1-2 รอบ ดังนั้น Time Complexity คือ O(N) ซึ่งรวดเร็วมากสำหรับ N≤100

💻ตัวอย่างโครงร่างโค้ด

Score Management Program 💻 C++
#include <iostream> #include <vector> using namespace std; // ฟังก์ชันคำนวณค่าเฉลี่ย double calculateAverage(const vector<int>& scores) { double sum = 0; for (int score : scores) { sum += score; } return sum / scores.size(); } // ฟังก์ชันหาค่าสูงสุด int findMax(const vector<int>& scores) { int maxScore = scores[0]; for (int score : scores) { if (score > maxScore) { maxScore = score; } } return maxScore; } int main() { int n; cout << "จำนวนนักเรียน: "; cin >> n; vector<int> scores(n); // รับคะแนน for (int i = 0; i < n; i++) { cout << "คะแนนนักเรียนคนที่ " << (i+1) << ": "; cin >> scores[i]; } // คำนวณผลลัพธ์ double average = calculateAverage(scores); int maxScore = findMax(scores); // นับจำนวนนักเรียนที่ได้คะแนนมากกว่าหรือเท่ากับค่าเฉลี่ย int countAboveAverage = 0; for (int score : scores) { if (score >= average) { countAboveAverage++; } } // แสดงผล cout << "คะแนนเฉลี่ย: " << average << endl; cout << "คะแนนสูงสุด: " << maxScore << endl; cout << "จำนวนนักเรียนที่ได้คะแนน >= ค่าเฉลี่ย: " << countAboveAverage << endl; return 0; }

โจทย์ที่ 2: การค้นหาคู่ผลรวม

Array/Vector & O(N²) vs O(N)

📋 โจทย์:

ให้ Vector ของตัวเลขจำนวนเต็ม V ที่มีขนาด N (โดยที่ N≤2000) และตัวเลขเป้าหมาย T จงตรวจสอบว่ามี ตัวเลขสองตัว ใน Vector ที่เมื่อนำมาบวกกันแล้วได้ผลรวมเท่ากับ T หรือไม่? ถ้าพบให้พิมพ์ YES ถ้าไม่พบให้พิมพ์ NO

📝 ตัวอย่าง:
Input V: [1, 5, 8, 12], Target T: 13
Output: YES (เพราะ 1+12=13 และ 5+8=13)

🧠แนวคิดการแก้ปัญหา (Focus on Complexity!)

มีสองทางเลือกหลักในการแก้ปัญหานี้:

💡 ทางเลือกที่ 1: การวนซ้ำซ้อน (O(N²))

ช้ากว่าแต่ทำได้

  • ใช้ for loop ตัวนอก (ดัชนี i) วนตั้งแต่ 0 ถึง N−1
  • ใช้ for loop ตัวใน (ดัชนี j) วนตั้งแต่ i+1 ถึง N−1
  • ใน Loop ตัวใน ให้ตรวจสอบว่า V[i] + V[j] == T หรือไม่
  • ถ้าใช่ให้พิมพ์ YES แล้ว return ออกจากฟังก์ชันหลักทันที
  • ถ้าวนจนจบแล้วไม่เจอคู่ผลรวมเลย ให้พิมพ์ NO
📊วิเคราะห์:

สำหรับ N≤2000 การทำงานประมาณ 4×10⁶ ครั้ง (N²) ยังถือว่า รวดเร็วพอ (อยู่ในเกณฑ์ปลอดภัย)

O(N²) Solution 💻 C++
#include <iostream> #include <vector> using namespace std; bool findTwoSum(vector<int>& arr, int target) { int n = arr.size(); // วนซ้ำซ้อน O(N²) for (int i = 0; i < n; i++) { for (int j = i + 1; j < n; j++) { if (arr[i] + arr[j] == target) { return true; // พบคู่ผลรวมแล้ว } } } return false; // ไม่พบคู่ผลรวม } int main() { int n, target; cout << "ขนาด Vector: "; cin >> n; vector<int> arr(n); cout << "ใส่ตัวเลข " << n << " ตัว: "; for (int i = 0; i < n; i++) { cin >> arr[i]; } cout << "เป้าหมาย (Target): "; cin >> target; if (findTwoSum(arr, target)) { cout << "YES" << endl; } else { cout << "NO" << endl; } return 0; }

🚀 ทางเลือกที่ 2: การใช้ Hashing/Sorting (Advanced)

เร็วกว่า O(N) หรือ O(NlogN)

(สำหรับการเรียนรู้เพิ่มเติม): ในค่ายจริง คุณอาจจะถูกบังคับให้ใช้วิธีที่เร็วขึ้นสำหรับ N≥10⁵ โดยการใช้:

  • std::map (Hashing): เก็บตัวเลขที่เจอแล้วไว้ใน Map แล้วหาคู่ของมัน
  • การ Sort ข้อมูลก่อน (Sorting): เรียงข้อมูลก่อนแล้วใช้ Two Pointers
📊เป้าหมาย:

เพื่อลด Time Complexity จาก O(N²) เป็น O(N) หรือ O(NlogN)

💡 หมายเหตุ: วิธีนี้จะเรียนรู้ในค่ายจริง ตอนนี้ให้มุ่งเน้นที่การทำความเข้าใจวิธี O(N²) ให้ดีก่อน

  1. 1
    ลงมือเขียนโค้ด: เขียน Solution สำหรับ โจทย์ที่ 1 และ โจทย์ที่ 2 (แบบ O(N²) เป็นหลัก) ใน VS Code

    ใช้ Debugger: ตั้ง Breakpoint ใน for loop ของโจทย์ที่ 1 เพื่อตรวจสอบว่าค่าเฉลี่ยที่คุณคำนวณมานั้นถูกต้องหรือไม่ ก่อนที่จะไปนับจำนวนนักเรียน
  3. 3
    ทดสอบขอบเขต (Edge Cases): ลองรันโจทย์ที่ 1 ด้วย Input N=1 (นักเรียนคนเดียว) และ N=100 เพื่อยืนยันว่าโปรแกรมของคุณทำงานได้ถูกต้องภายใต้ข้อจำกัด
