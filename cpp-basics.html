1. โครงสร้างพื้นฐานของโปรแกรม C++

ทุกโปรแกรมภาษา C++ จะมีโครงสร้างหลักที่คล้ายกัน ซึ่งนักเรียนต้องจำและเข้าใจส่วนประกอบต่อไปนี้

🏗️ โครงสร้างโปรแกรม C++

#include

ดึงไลบรารี

int main()

ฟังก์ชันหลัก

{ โค้ด }

เนื้อหาโปรแกรม

return 0;

จบโปรแกรม

📚1.1 ส่วนการประกาศไลบรารี (#include)

เป็นส่วนที่ใช้ดึงฟังก์ชันหรือเครื่องมือต่าง ๆ ที่ภาษา C++ เตรียมไว้ให้มาใช้งาน

📖 #include <iostream>: คือการดึงไลบรารีสำหรับจัดการการ Input (รับข้อมูล) และ Output (แสดงผล) ซึ่งเราจะใช้ตลอดหลักสูตร

🎯1.2 ฟังก์ชันหลัก (int main())

โปรแกรมจะเริ่มต้นทำงานจากฟังก์ชันนี้เสมอ เปรียบเสมือนเป็นจุดเริ่มต้นและจุดสิ้นสุดของการรันโปรแกรม

  • int main(): หมายถึงฟังก์ชันนี้จะส่งค่ากลับเป็นจำนวนเต็ม (int) เมื่อทำงานเสร็จสิ้น
  • return 0; เป็นคำสั่งสุดท้ายในฟังก์ชันหลัก โดยทั่วไปการส่งค่า 0 กลับไปจะหมายถึง "โปรแกรมทำงานเสร็จสมบูรณ์โดยไม่มีข้อผิดพลาด"
ตัวอย่างโครงสร้างพื้นฐาน 💻 C++
#include <iostream> // ส่วนดึงไลบรารี Input/Output int main() { // โค้ดโปรแกรมของเราจะอยู่ตรงนี้ return 0; // บอกว่าโปรแกรมจบสมบูรณ์ }
2. การรับและแสดงผลข้อมูล (Input/Output)

เราใช้ std::cout สำหรับการแสดงผล และ std::cin สำหรับการรับข้อมูล

📤

std::cout

สำหรับแสดงผลข้อมูลออกหน้าจอ

📥

std::cin

สำหรับรับข้อมูลจากผู้ใช้

📤2.1 การแสดงผล (Output) ด้วย std::cout

ใช้ในการพิมพ์ข้อความ หรือค่าตัวแปรออกทางหน้าจอ (Terminal)

  • std::cout << "ข้อความ"; ใช้เครื่องหมาย << (insertion operator)
  • \n หรือ std::endl: ใช้สำหรับการขึ้นบรรทัดใหม่
ตัวอย่างการแสดงผล 💻 C++
#include <iostream> int main() { std::cout << "สวัสดีครับ สอวน. คอมพ์!"; // พิมพ์ข้อความ std::cout << "\n"; // ขึ้นบรรทัดใหม่ int age = 15; std::cout << "ฉันอายุ: " << age << " ปี" << std::endl; // เชื่อมข้อความกับตัวแปร return 0; }
สวัสดีครับ สอวน. คอมพ์! ฉันอายุ: 15 ปี

📥2.2 การรับข้อมูล (Input) ด้วย std::cin

ใช้ในการรับค่าจากผู้ใช้ที่พิมพ์ผ่านคีย์บอร์ด แล้วนำไปเก็บไว้ในตัวแปร

  • std::cin >> ตัวแปร; ใช้เครื่องหมาย >> (extraction operator)
ตัวอย่างการรับข้อมูล 💻 C++
#include <iostream> int main() { int number; // ประกาศตัวแปรชนิดจำนวนเต็ม std::cout << "กรุณาใส่ตัวเลข: "; std::cin >> number; // รับค่าที่ผู้ใช้พิมพ์ แล้วเก็บในตัวแปร 'number' std::cout << "คุณป้อนเลข: " << number << std::endl; return 0; }

📝 หมายเหตุ:

ในการแข่งขัน เรามักจะใช้ using namespace std; เพื่อลดความยุ่งยากในการพิมพ์ std:: ซ้ำ ๆ แต่สำหรับการเรียนรู้พื้นฐาน ให้เข้าใจว่า cout และ cin อยู่ใน std Namespace ครับ

3. ชนิดข้อมูล (Data Types) ที่ควรรู้จัก

การเลือกใช้ชนิดข้อมูลที่เหมาะสมเป็นสิ่งสำคัญมากในการแข่งขัน เนื่องจากมีผลต่อหน่วยความจำและความถูกต้องของค่าที่เก็บ

ชนิดข้อมูล (Type) ขนาด (Size) โดยประมาณ ช่วงค่า (Range) ที่เก็บได้ ใช้เมื่อไหร่?
int 4 Bytes ประมาณ ±2 พันล้าน ใช้สำหรับเก็บจำนวนเต็มทั่วไป (ส่วนใหญ่สำหรับค่าที่ไม่เกิน 10⁹)
long long 8 Bytes ประมาณ ±9×10¹⁸ สำคัญมาก! ใช้สำหรับจำนวนเต็มขนาดใหญ่ (ถ้าโจทย์ระบุว่าตัวเลขเกิน 2 พันล้าน ต้องใช้ตัวนี้)
double 8 Bytes สำหรับทศนิยมความละเอียดสูง ใช้สำหรับเก็บจำนวนจริง (Real Number) หรือค่าที่มีจุดทศนิยม
char 1 Byte ตัวอักษรเดียว ใช้สำหรับเก็บตัวอักษร 1 ตัว (เช่น 'A', 'b', '9')
bool 1 Byte true หรือ false ใช้สำหรับเก็บค่าความจริง/เท็จ

📝การประกาศตัวแปร

รูปแบบคือ: [ชนิดข้อมูล] [ชื่อตัวแปร]; หรือ [ชนิดข้อมูล] [ชื่อตัวแปร] = [ค่าเริ่มต้น];

ตัวอย่างการประกาศตัวแปร 💻 C++
#include <iostream> int main() { int score = 100; // จำนวนเต็ม long long population = 7000000000LL; // จำนวนเต็มขนาดใหญ่ (ใช้ LL ต่อท้าย) double pi = 3.14159; // จำนวนทศนิยม char grade = 'A'; // ตัวอักษร std::cout << "คะแนน: " << score << std::endl; std::cout << "ประชากรโลก: " << population << std::endl; return 0; }

📋 สรุปการปฏิบัติ (Quick Check)

  • โครงสร้าง: ต้องมี #include <iostream> และ int main() { ... return 0; } เสมอ
  • Input/Output: ใช้ std::cout << ... และ std::cin >> ...
  • Data Types: ถ้าตัวเลขใหญ่มาก (เกิน 2×10⁹) ให้ใช้ long long ทันที

🎯 ขั้นตอนต่อไป

ในชั่วโมงถัดไป เราจะนำความรู้เรื่องตัวแปรเหล่านี้ ไปใช้ร่วมกับ ตัวดำเนินการ (Operators) และ คำสั่งเงื่อนไข (If/Else) เพื่อให้โปรแกรมสามารถตัดสินใจได้!
