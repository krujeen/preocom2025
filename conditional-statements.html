1. คำสั่ง if และ else

🔍1.1 if (ถ้า)

ใช้เมื่อคุณต้องการให้ชุดคำสั่งทำงาน ก็ต่อเมื่อ เงื่อนไขที่กำหนดเป็นจริงเท่านั้น

if (เงื่อนไข) { // ชุดคำสั่งจะทำงานเมื่อ 'เงื่อนไข' เป็นจริง (true) }

🔄1.2 else (มิฉะนั้น)

ใช้เพื่อกำหนดชุดคำสั่งที่จะทำงาน เมื่อ เงื่อนไขใน if ข้างต้นเป็นเท็จ (false)

if (เงื่อนไข) { // ทำเมื่อเงื่อนไขเป็นจริง } else { // ทำเมื่อเงื่อนไขเป็นเท็จ (คือไม่ได้เข้า if) }

💡ตัวอย่าง: การตรวจสอบว่าตัวเลขเป็นเลขคู่หรือเลขคี่

Even/Odd Checker 💻 C++
#include <iostream> using namespace std; // ใช้ namespace std เพื่อลดการพิมพ์ std:: int main() { int num; cout << "Enter a number: "; cin >> num; // ตรวจสอบเงื่อนไข: num หาร 2 แล้วเหลือเศษ 0 หรือไม่ if (num % 2 == 0) { cout << num << " is an Even number." << endl; } else { cout << num << " is an Odd number." << endl; } return 0; }
💭 คำอธิบาย:

ใช้ตัวดำเนินการ % (modulo) เพื่อหาเศษจากการหาร ถ้าหาร 2 แล้วเศษเป็น 0 แสดงว่าเป็นเลขคู่

2. คำสั่ง else if (มิฉะนั้น ถ้า...)

ใช้เมื่อคุณต้องการตรวจสอบเงื่อนไขหลายเงื่อนไขตามลำดับ โปรแกรมจะตรวจสอบจากบนลงล่าง และจะทำในบล็อกแรกที่เงื่อนไขเป็นจริงเท่านั้น

if (เงื่อนไข A) { // ทำเมื่อ A เป็นจริง } else if (เงื่อนไข B) { // ทำเมื่อ B เป็นจริง (และ A เป็นเท็จ) } else if (เงื่อนไข C) { // ทำเมื่อ C เป็นจริง (และ A, B เป็นเท็จ) } else { // ทำเมื่อทุกเงื่อนไขข้างต้นเป็นเท็จทั้งหมด }

🎓ตัวอย่าง: การให้เกรดตามคะแนน

Grade Calculator 💻 C++
#include <iostream> using namespace std; int main() { int score; cout << "Enter score: "; cin >> score; if (score >= 80) { cout << "Grade A" << endl; } else if (score >= 70) { // จะมาตรวจสอบตรงนี้ก็ต่อเมื่อ score < 80 เท่านั้น cout << "Grade B" << endl; } else if (score >= 60) { // จะมาตรวจสอบตรงนี้ก็ต่อเมื่อ score < 70 เท่านั้น cout << "Grade C" << endl; } else { cout << "Grade F" << endl; } return 0; }
📝 ตัวอย่างการทำงาน:
  • Input: 85 → Output: Grade A
  • Input: 75 → Output: Grade B
  • Input: 65 → Output: Grade C
  • Input: 50 → Output: Grade F

3. ตัวดำเนินการเปรียบเทียบ (Comparison Operators)

ตัวดำเนินการเหล่านี้ใช้สำหรับสร้าง "เงื่อนไข" ในวงเล็บของคำสั่ง if ผลลัพธ์ที่ได้จะเป็นค่าความจริง (true หรือ false) เสมอ

ตัวดำเนินการ ความหมาย ตัวอย่าง ผลลัพธ์ (สมมติ x=5, y=10)
== เท่ากับ x == 5 true
!= ไม่เท่ากับ x != y true
> มากกว่า y > x true
< น้อยกว่า x < 5 false
>= มากกว่าหรือเท่ากับ y >= 10 true
<= น้อยกว่าหรือเท่ากับ x <= 4 false
4. ตัวดำเนินการตรรกะ (Logical Operators)

ใช้เพื่อรวมเงื่อนไขย่อย ๆ หลายเงื่อนไขเข้าด้วยกันเพื่อสร้างเงื่อนไขที่ซับซ้อนขึ้น

🤝AND (&&)

ความหมาย: เป็นจริงก็ต่อเมื่อ ทุกเงื่อนไข เป็นจริง

(x > 5 && x < 15) // true เมื่อ x มากกว่า 5 และ น้อยกว่า 15

ตัวอย่าง: (x=10) → true

🔄OR (||)

ความหมาย: เป็นจริงเมื่อ เงื่อนไขใดเงื่อนไขหนึ่ง เป็นจริง

(x < 5 || x > 15) // true เมื่อ x น้อยกว่า 5 หรือ มากกว่า 15

ตัวอย่าง: (x=3) → true

🚫NOT (!)

ความหมาย: กลับค่าความจริง (จริง → เท็จ, เท็จ → จริง)

!(x < 5) // true เมื่อ x ไม่น้อยกว่า 5

ตัวอย่าง: (x=10) → true

🎯ตัวอย่าง: ตรวจสอบว่าคะแนนอยู่ในช่วง [70,80)

คือ ≥70 และ <80

Range Checker 💻 C++
if (score >= 70 && score < 80) { cout << "Grade B" << endl; }

🏋️สรุปและแบบฝึกหัด

🔑จุดสำคัญที่ต้องจำ

  • เงื่อนไขซ้อนเงื่อนไข (Nested If): คุณสามารถใส่คำสั่ง if ซ้อนเข้าไปในบล็อกของ if หรือ else อื่น ๆ ได้ เพื่อให้โปรแกรมตัดสินใจแบบหลายระดับ
  • การใช้ bool: ผลลัพธ์ของเงื่อนไขคือชนิดข้อมูล bool ซึ่งสามารถเก็บค่า true หรือ false ได้
  • ลำดับการตรวจสอบ: ใน else if โปรแกรมจะตรวจสอบจากบนลงล่าง และหยุดที่เงื่อนไขแรกที่เป็นจริง

🧩 โจทย์ฝึกหัด: ปีอธิกสุรทิน (Leap Year)

จงเขียนโปรแกรมที่รับปี พ.ศ. เข้ามา แล้วตรวจสอบว่าปีนั้นเป็น ปีอธิกสุรทิน (Leap Year) หรือไม่

เงื่อนไข: หาร 400 ลงตัว หรือ (หาร 4 ลงตัวแต่ไม่หาร 100 ลงตัว)

💡 คำใบ้:

ใช้ตัวดำเนินการ % เพื่อตรวจสอบการหารลงตัว และใช้ && กับ || เพื่อรวมเงื่อนไข
