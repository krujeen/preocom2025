🔢for Loop

📊 เหมาะสำหรับ:

เมื่อรู้จำนวนรอบแน่นอน (นับ, ทำซ้ำ N ครั้ง)

🔄while Loop

🎯 เหมาะสำหรับ:

เมื่อไม่รู้จำนวนรอบแต่มีเงื่อนไขให้หยุด

1. for Loop: การวนซ้ำที่ทราบจำนวนรอบ

for Loop เป็นเครื่องมือที่ยอดเยี่ยมที่สุดเมื่อคุณทราบจำนวนครั้งที่ต้องการวนซ้ำอย่างชัดเจน (เช่น วน N ครั้ง, วนตั้งแต่ 1 ถึง 10)

for (การกำหนดค่าเริ่มต้น; เงื่อนไขการวนซ้ำ; การเปลี่ยนแปลงค่าในแต่ละรอบ) { // ชุดคำสั่งที่จะถูกทำซ้ำ }

🔢ตัวอย่าง: พิมพ์ตัวเลขตั้งแต่ 1 ถึง 5

1
กำหนดค่าเริ่มต้น
int i = 1
2
ตรวจสอบเงื่อนไข
i <= 5
3
ทำงานในบล็อก
cout << i
4
เปลี่ยนแปลงค่า
i++
Number Printer 💻 C++
#include <iostream> using namespace std; int main() { // 1. กำหนดค่าเริ่มต้น: int i = 1 (ตัวนับ i เริ่มที่ 1) // 2. เงื่อนไข: i <= 5 (วนซ้ำตราบใดที่ i น้อยกว่าหรือเท่ากับ 5) // 3. เปลี่ยนแปลง: i++ (เพิ่มค่า i ทีละ 1 หลังจบรอบ) for (int i = 1; i <= 5; i++) { cout << i << " "; } cout << endl; return 0; }
1 2 3 4 5

📝 หมายเหตุ: i++ คือการเพิ่มค่า i ขึ้น 1 (i=i+1) และ i-- คือการลดค่า i ลง 1

2. while Loop: การวนซ้ำตามเงื่อนไข

while Loop ใช้เมื่อคุณไม่ทราบจำนวนรอบที่แน่นอน แต่ต้องการให้โปรแกรมทำงานต่อไปตราบใดที่เงื่อนไขใดยังคงเป็นจริง

while (เงื่อนไขการวนซ้ำ) { // ชุดคำสั่งที่จะถูกทำซ้ำ // ต้องมีการเปลี่ยนแปลงบางอย่างที่ทำให้เงื่อนไขเป็นเท็จในที่สุด! }

🔄ตัวอย่าง: รับค่าตัวเลขไปเรื่อย ๆ จนกว่าจะป้อน 0

Input Loop 💻 C++
#include <iostream> using namespace std; int main() { int num = -1; // กำหนดค่าเริ่มต้นที่ไม่ใช่ 0 เพื่อให้เข้า Loop ครั้งแรก // วนซ้ำตราบใดที่ num ไม่เท่ากับ 0 while (num != 0) { cout << "Enter a number (0 to exit): "; cin >> num; cout << "You entered: " << num << endl; } cout << "Program exited." << endl; return 0; }
Enter a number (0 to exit): 5 You entered: 5 Enter a number (0 to exit): 3 You entered: 3 Enter a number (0 to exit): 0 You entered: 0 Program exited.
⚠️ข้อควรระวัง: Infinite Loop

ถ้าในบล็อกของ while Loop ไม่มีคำสั่งที่ทำให้ เงื่อนไขเป็นเท็จ (เช่น ลืมเพิ่มค่า i++ หรือลืมรับค่าใหม่) โปรแกรมจะเกิด Infinite Loop (วนซ้ำไม่รู้จบ) และทำให้โปรแกรมค้าง

3. คำสั่งควบคุม Loop พิเศษ

มีคำสั่งพิเศษ 2 คำสั่งที่ช่วยให้เราควบคุมการทำงานของ Loop ได้ยืดหยุ่นมากขึ้น

🚪break

ใช้สำหรับ ออกจาก Loop ทันที เมื่อคำสั่งนี้ถูกรัน ไม่ว่าจะยังเหลือรอบการวนซ้ำอยู่หรือไม่ก็ตาม

Break Example 💻 C++
for (int i = 1; i <= 10; i++) { if (i == 7) { cout << "Found 7! Breaking..." << endl; break; // ออกจาก for loop ทันที } cout << i << " "; }
1 2 3 4 5 6 Found 7! Breaking...
⏭️continue

ใช้สำหรับ ข้ามการทำงานที่เหลือ ในรอบปัจจุบันของ Loop แล้วไปเริ่มต้นรอบใหม่ทันที

Continue Example 💻 C++
for (int i = 1; i <= 5; i++) { if (i % 2 == 0) { continue; // ข้ามการทำงานที่เหลือ (คือ cout) แล้วไปรอบ i ถัดไป } cout << i << " "; } cout << endl;
1 3 5
4. การวนซ้ำซ้อนกัน (Nested Loops)

คุณสามารถใส่ Loop หนึ่งไว้ในอีก Loop หนึ่งได้ การวนซ้ำซ้อนกันนี้มีประโยชน์มากสำหรับการทำงานกับข้อมูลสองมิติ หรือการทำงานที่ต้องใช้การตรวจสอบคู่

🔄 แนวคิดของ Nested Loop

Outer Loop (แถว)
Inner Loop (คอลัมน์)
รันครบทุกรอบก่อน Outer เพิ่ม

✖️ตัวอย่าง: การสร้างตารางสูตรคูณ (วนซ้ำ 2 ชั้น)

Multiplication Table 💻 C++
for (int i = 1; i <= 3; i++) { // Outer Loop (แถว) for (int j = 1; j <= 3; j++) { // Inner Loop (คอลัมน์) // Inner Loop จะรันครบทุกรอบของ j ก่อนที่ Outer Loop จะเพิ่มค่า i cout << i << "x" << j << "=" << (i * j) << "\t"; // \t คือ Tab } cout << endl; // ขึ้นบรรทัดใหม่เมื่อจบรอบ Outer Loop }
1x1=1 1x2=2 1x3=3 2x1=2 2x2=4 2x3=6 3x1=3 3x2=6 3x3=9

📋สรุปการปฏิบัติ (Quick Check)

🔢 for Loop

เหมาะสำหรับเมื่อ รู้จำนวนรอบ แน่นอน (นับ, ทำซ้ำ)

🔄 while Loop

เหมาะสำหรับเมื่อ ไม่รู้จำนวนรอบ แต่มีเงื่อนไขให้หยุด

🚪 break/continue

ใช้ควบคุมทิศทางการทำงานภายใน Loop

🔄 Nested Loops

สำหรับข้อมูลสองมิติหรือการตรวจสอบคู่

🏋️โจทย์ฝึกหัด

🧮 โจทย์: คำนวณ Factorial

จงเขียนโปรแกรมที่รับตัวเลข N เข้ามา แล้วคำนวณค่า Factorial ของ N (N!) โดยใช้ for Loop

ตัวอย่าง: 5! = 5 × 4 × 3 × 2 × 1 = 120
