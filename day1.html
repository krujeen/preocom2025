ชั่วโมงที่ 1

🛠️ การเตรียมเครื่องมือ: VS Code และ Compiler

รายละเอียด (Details):

  • แนะนำ Visual Studio Code (VS Code) และเหตุผลในการใช้ในการแข่งขัน
  • การติดตั้ง MinGW (หรือ g++ บน Linux/macOS) เพื่อใช้เป็น C++ Compiler
  • ตรวจสอบการติดตั้ง g++ และ gdb

สิ่งที่นักเรียนควรทำได้ (Outcome):

ติดตั้ง VS Code และ Compiler พร้อมใช้งาน สามารถเรียกใช้ g++ จาก Command Line ได้

ชั่วโมงที่ 2

💻 ตั้งค่า VS Code สำหรับ C++

รายละเอียด (Details):

  • การติดตั้ง Extensions ที่จำเป็น: C/C++ Extension Pack
  • การตั้งค่า Tasks และ Launch Configurations เบื้องต้นสำหรับการ Compile และ Run C++

สิ่งที่นักเรียนควรทำได้ (Outcome):

ตั้งค่า VS Code ให้สามารถ Compile และ Run ไฟล์ .cpp ได้ด้วยการกดปุ่ม (เช่น F5)

ชั่วโมงที่ 3

🚀 พื้นฐานภาษา C++ (Input/Output & Data Types)

รายละเอียด (Details):

  • โครงสร้างพื้นฐานของโปรแกรม C++: #include <iostream>, int main(), return 0;
  • การใช้ฟังก์ชัน Input/Output พื้นฐาน: std::cin และ std::cout
  • แนะนำ ชนิดข้อมูล (Data Types) สำคัญ: int, long long, double, char, bool

สิ่งที่นักเรียนควรทำได้ (Outcome):

เข้าใจโครงสร้างโปรแกรม C++ และสามารถรับ/แสดงผลข้อมูลพื้นฐานได้ถูกต้อง

ชั่วโมงที่ 4

🔀 โครงสร้างควบคุม: เงื่อนไข (Conditional Statements)

รายละเอียด (Details):

  • การใช้ if, else if, และ else
  • ตัวดำเนินการตรรกะ (Logical Operators): &&, ||, !
  • ตัวดำเนินการเปรียบเทียบ (Comparison Operators): ==, !=, <, >, <=, >=
  • การเขียนเงื่อนไขที่ซับซ้อน

สิ่งที่นักเรียนควรทำได้ (Outcome):

สามารถเขียนโปรแกรมที่ตัดสินใจทำงานตามเงื่อนไขต่าง ๆ ได้อย่างถูกต้อง

ชั่วโมงที่ 5

🔄 โครงสร้างควบคุม: วนซ้ำ (Loops)

รายละเอียด (Details):

  • การใช้ for loop (เน้นการใช้สำหรับการวนซ้ำที่ทราบจำนวนรอบ)
  • การใช้ while loop (เน้นการวนซ้ำตามเงื่อนไข)
  • คำสั่ง break และ continue
  • การใช้ nested loops (การวนซ้ำซ้อนกัน)

สิ่งที่นักเรียนควรทำได้ (Outcome):

สามารถใช้คำสั่งวนซ้ำเพื่อประมวลผลข้อมูลซ้ำ ๆ หรือทำงานที่ต้องทำหลายครั้ง

ชั่วโมงที่ 6

📝 ฝึกปฏิบัติ 1: แก้โจทย์เบื้องต้น

รายละเอียด (Details):

  • นำความรู้ทั้งหมดมาแก้โจทย์ง่าย ๆ ที่ต้องใช้ Input/Output, เงื่อนไข, และการวนซ้ำ
  • เน้นการอ่านโจทย์ การวิเคราะห์ และการแปลงแนวคิดเป็นโค้ด C++
  • ฝึกการ debug และแก้ไขข้อผิดพลาดเบื้องต้น

สิ่งที่นักเรียนควรทำได้ (Outcome):

สามารถเขียนโปรแกรม C++ ที่ทำงานตามโจทย์ระดับพื้นฐานได้อย่างครบถ้วน

📚 สรุปวันที่ 1

ในวันแรก นักเรียนจะได้เรียนรู้พื้นฐานที่สำคัญที่สุดของการเขียนโปรแกรม C++ ตั้งแต่การติดตั้งเครื่องมือไปจนถึงการใช้โครงสร้างควบคุมต่าง ๆ ความรู้เหล่านี้จะเป็นรากฐานสำคัญสำหรับการเรียนรู้ในวันที่ 2
