ฟังก์ชัน (Functions) > โครงสร้างข้อมูล 2: เวกเตอร์ (Vectors)

🎯 เป้าหมายของบทนี้

เวกเตอร์ (std::vector) ในภาษา C++ คือสิ่งที่เรียกว่า Dynamic Array (อาร์เรย์พลวัต) มันทำงานคล้ายอาร์เรย์ แต่มีข้อดีที่เหนือกว่ามาก

📈

ขนาดเปลี่ยนแปลงได้

สามารถเพิ่มหรือลดจำนวนสมาชิกได้ตลอดเวลา ไม่ต้องกำหนดขนาดตายตัวตั้งแต่ต้น

🧠

จัดการหน่วยความจำเอง

ไม่ต้องกังวลเรื่องการจองหน่วยความจำที่ซับซ้อน

🚨 สิ่งสำคัญ:

ในการใช้ std::vector คุณต้อง #include <vector> เสมอ

1. การประกาศและเริ่มต้นใช้งาน Vector

📝1.1 การประกาศ Vector เปล่า

// ชนิดข้อมูล <ชนิดข้อมูล> ชื่อเวกเตอร์; vector<int> numbers; // เวกเตอร์สำหรับเก็บ int (ว่างเปล่า) vector<string> names; // เวกเตอร์สำหรับเก็บ string (ว่างเปล่า)

💻ตัวอย่าง: การประกาศ Vector พื้นฐาน

Vector Declaration 💻 C++
#include <vector> #include <iostream> using namespace std; int main() { // ประกาศ Vector สำหรับเก็บ int (ว่างเปล่า) vector<int> numbers; // ประกาศ Vector สำหรับเก็บ string (ว่างเปล่า) vector<string> names; return 0; }

🔧1.2 การประกาศพร้อมกำหนดขนาดเริ่มต้น

คุณสามารถกำหนดขนาดและค่าเริ่มต้นให้กับสมาชิกทั้งหมดได้

// vector<ชนิดข้อมูล> ชื่อเวกเตอร์(ขนาด, ค่าเริ่มต้น); vector<int> fixed_size(10, 0); // เวกเตอร์ขนาด 10 ตัว โดยทุกตัวมีค่าเป็น 0
2. การจัดการขนาดและเพิ่มสมาชิก

นี่คือฟังก์ชันที่ใช้บ่อยที่สุดของ Vector ที่ทำให้มันเหนือกว่า Array ธรรมดา

➕push_back()

การใช้งาน: เพิ่มสมาชิกใหม่เข้าไปที่ ท้าย ของ Vector โดยอัตโนมัติ

vector<int> scores; scores.push_back(10); // [10] scores.push_back(20); // [10, 20] scores.push_back(35); // [10, 20, 35]
📏size()

การใช้งาน: ส่งค่ากลับมาเป็นจำนวนสมาชิกปัจจุบันใน Vector

cout << scores.size() << endl; // ผลลัพธ์: 3
➖pop_back()

การใช้งาน: ลบสมาชิกที่อยู่ตำแหน่งสุดท้ายออกไป 1 ตัว

scores.pop_back(); // ลบ 35 ออกไป: [10, 20] cout << scores.size() << endl; // ผลลัพธ์: 2

🔄ตัวอย่าง: การจัดการขนาด Vector

Vector Size Management 💻 C++
#include <vector> #include <iostream> using namespace std; int main() { vector<int> scores; cout << "Initial size: " << scores.size() << endl; // 0 // เพิ่มสมาชิก scores.push_back(10); scores.push_back(20); scores.push_back(35); cout << "After adding 3 elements: " << scores.size() << endl; // 3 // ลบสมาชิกตัวสุดท้าย scores.pop_back(); cout << "After removing last element: " << scores.size() << endl; // 2 return 0; }
3. การเข้าถึงสมาชิก (Accessing Elements)

🎯3.1 การเข้าถึงด้วยดัชนี: [ ]

เหมือนกับ Array ธรรมดา ดัชนีจะเริ่มต้นที่ 0 เสมอ

📍ตัวอย่าง: การเข้าถึงด้วยดัชนี

Vector Indexing 💻 C++
vector<int> data = {1, 5, 8, 12}; cout << "Element at index 2: " << data[2] << endl; // ผลลัพธ์: 8

🔚3.2 การเข้าถึงสมาชิกตัวสุดท้าย: back()

ส่งค่าของสมาชิกตัวสุดท้ายใน Vector กลับมา

Back() Function 💻 C++
cout << "Last element: " << data.back() << endl; // ผลลัพธ์: 12
4. การใช้งานร่วมกับ Loop

เราใช้ for loop ในการวนซ้ำสมาชิกใน Vector โดยใช้ size() ในการกำหนดขอบเขตของการวนซ้ำ

🔄ตัวอย่าง: การวนซ้ำมาตรฐาน

🔁การวนซ้ำแบบ Traditional For Loop

Traditional For Loop 💻 C++
vector<int> myVector; myVector.push_back(100); myVector.push_back(200); myVector.push_back(300); // วนจากดัชนี 0 จนถึง size() - 1 for (int i = 0; i < myVector.size(); i++) { cout << "Value at index " << i << ": " << myVector[i] << endl; } /* ผลลัพธ์: Value at index 0: 100 Value at index 1: 200 Value at index 2: 300 */

✨ตัวอย่าง: Range-based for Loop (รูปแบบที่อ่านง่ายกว่า)

ตั้งแต่ C++11 เป็นต้นมา การใช้ Range-based for loop ทำให้การวนซ้ำ Vector ง่ายขึ้นมาก

🚀Range-based For Loop

Modern C++ Style 💻 C++
// สำหรับทุกๆ ตัวแปร 'element' ชนิด int ใน myVector for (int element : myVector) { cout << element << " "; } // ผลลัพธ์: 100 200 300
🔧 เคล็ดลับ:

หากต้องการแก้ไขค่าใน Loop ให้ใช้ Reference (&) ใน Range-based loop: for (int &element : myVector)

5. เวกเตอร์ 2 มิติ (2D Vectors)

เวกเตอร์ 2 มิติคือ "เวกเตอร์ของเวกเตอร์" ใช้แทน Array 2 มิติ แต่มีความยืดหยุ่นในการปรับขนาดแถวและคอลัมน์

📊 ตัวอย่าง: เวกเตอร์ 2 มิติ

2D Vector Example 💻 C++
// ประกาศ Vector ที่เก็บ Vector ของ int vector<vector<int>> matrix; // ตัวอย่างการเพิ่มข้อมูล vector<int> row1 = {1, 2, 3}; vector<int> row2 = {4, 5}; // สังเกตว่าแถวมีขนาดไม่เท่ากันได้ matrix.push_back(row1); matrix.push_back(row2); // การเข้าถึง: matrix[แถว][คอลัมน์] cout << matrix[1][0] << endl; // ผลลัพธ์: 4

🏋️โจทย์ฝึกหัด

🧩 โจทย์: โปรแกรมรับตัวเลขแบบ Dynamic

จงเขียนโปรแกรมที่รับตัวเลขจำนวนเต็มมาเรื่อย ๆ จนกระทั่งผู้ใช้กรอกตัวเลข 0 (ศูนย์) จากนั้นให้ใช้ std::vector ในการเก็บตัวเลขทั้งหมด (ที่ไม่ใช่ 0) แล้วพิมพ์ตัวเลขเหล่านั้นออกมา เรียงจากหลังไปหน้า (ตัวสุดท้ายที่รับเข้ามาก่อน)

💡 คำใบ้:

ใช้ while loop สำหรับรับข้อมูล, push_back() สำหรับเก็บข้อมูล, และ for loop จากหลังไปหน้าสำหรับแสดงผล

🔑จุดสำคัญที่ต้องจำ

  • การ Include: ต้อง #include <vector> เสมอก่อนใช้งาน
  • Dynamic Size: Vector สามารถเปลี่ยนขนาดได้ตลอดเวลา ไม่เหมือน Array
  • ฟังก์ชันสำคัญ: push_back(), pop_back(), size(), back() คือฟังก์ชันที่ใช้บ่อยที่สุด
  • การเข้าถึง: ใช้ [] เหมือน Array หรือใช้ Range-based for loop แบบ C++11
  • 2D Vector: เหมาะสำหรับข้อมูลแบบตารางที่ขนาดไม่แน่นอน

🎯 ขั้นตอนต่อไป

การใช้ Vector เป็นทักษะสำคัญที่ต้องใช้ตลอดค่ายครับ หากมีข้อสงสัยเกี่ยวกับการใช้ push_back() หรือ size() ถามได้เลยนะครับ!
