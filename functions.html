🎯 ฟังก์ชันคืออะไร?

ฟังก์ชัน (Function) คือชุดคำสั่งที่ถูกรวมเข้าด้วยกันและตั้งชื่อไว้ เพื่อให้เราสามารถเรียกใช้งานชุดคำสั่งนั้นซ้ำ ๆ ได้ตามต้องการ

1. โครงสร้างพื้นฐานของฟังก์ชัน

ทุกฟังก์ชันจะมี 3 ส่วนหลัก ๆ ที่ต้องกำหนด:

ส่วนประกอบ คำอธิบาย
ชนิดข้อมูลที่ส่งกลับ (Return Type) ฟังก์ชันจะส่งค่าอะไรกลับไปให้ผู้เรียกใช้ (เช่น int, double, void)
ชื่อฟังก์ชัน (Function Name) ชื่อที่เราจะใช้เรียกฟังก์ชันนี้
พารามิเตอร์ (Parameters) ข้อมูลที่ฟังก์ชันต้องการเพื่อทำงาน (ถ้าไม่มี ให้ใส่ () เปล่า)
// ชนิดข้อมูลที่ส่งกลับ ชื่อฟังก์ชัน (ชนิดข้อมูล พารามิเตอร์1, ชนิดข้อมูล พารามิเตอร์2, ...); int findMax(int a, int b); // ฟังก์ชันหาค่ามากสุด รับ int 2 ตัว ส่งกลับเป็น int void printGreeting(string name); // ฟังก์ชันพิมพ์คำทักทาย ไม่ส่งค่ากลับ (void)
2. ฟังก์ชันที่ไม่ส่งค่ากลับ (void)

ฟังก์ชันชนิด void คือฟังก์ชันที่ทำงานบางอย่าง (เช่น พิมพ์ข้อความ หรือแก้ไขค่าตัวแปร) แต่ ไม่ส่งค่ากลับ ไปยังจุดที่เรียกใช้

🖨️ตัวอย่าง: ฟังก์ชันพิมพ์เส้นบรรทัด

Void Function Example 💻 C++
#include <iostream> using namespace std; // นิยามฟังก์ชัน: ไม่ส่งค่ากลับ (void) และไม่รับพารามิเตอร์ void printLine() { cout << "--------------------" << endl; } int main() { printLine(); // เรียกใช้ฟังก์ชัน cout << "Welcome to the Camp!" << endl; printLine(); // เรียกใช้ซ้ำอีกครั้ง return 0; }
-------------------- Welcome to the Camp! --------------------
3. ฟังก์ชันที่ส่งค่ากลับ (Non-void)

ฟังก์ชันชนิดอื่น ๆ (เช่น int, double, bool) ต้องมีการใช้คำสั่ง return เพื่อส่งค่ากลับไปยังจุดที่เรียกใช้

📊ตัวอย่าง: ฟังก์ชันยกกำลังสอง

Return Function Example 💻 C++
#include <iostream> using namespace std; // นิยามฟังก์ชัน: ส่งค่ากลับเป็น int และรับพารามิเตอร์ int 1 ตัว int square(int number) { return number * number; // คำนวณผลลัพธ์และส่งกลับ } int main() { int x = 5; // รับค่าที่ส่งกลับจากฟังก์ชันมาเก็บในตัวแปร result int result = square(x); cout << "The square of " << x << " is " << result << endl; // ผลลัพธ์: 25 // หรือเรียกใช้โดยตรงในการแสดงผล cout << "The square of 10 is " << square(10) << endl; // ผลลัพธ์: 100 return 0; }
The square of 5 is 25 The square of 10 is 100
4. การส่งผ่านพารามิเตอร์ (Parameter Passing)
📝4.1 การส่งผ่านแบบคัดลอกค่า (Pass by Value)

เมื่อส่งตัวแปรเข้าไปในฟังก์ชัน ฟังก์ชันจะได้รับสำเนา (Copy) ของค่านั้น

การแก้ไขค่าของตัวแปรภายในฟังก์ชัน จะไม่ส่งผลกระทบต่อตัวแปรต้นฉบับ ที่อยู่นอกฟังก์ชัน

🔗4.2 การส่งผ่านแบบอ้างอิง (Pass by Reference)

ใช้เครื่องหมาย & ที่หน้าชื่อพารามิเตอร์ (เช่น int &a)

ฟังก์ชันจะได้รับที่อยู่ (Reference) ของตัวแปรต้นฉบับ

การแก้ไขค่าของตัวแปรภายในฟังก์ชัน จะส่งผลกระทบต่อตัวแปรต้นฉบับโดยตรง

🔍 เปรียบเทียบ Pass by Value VS Pass by Reference

📝Pass by Value
Pass by Value 💻 C++
void modifyValue(int a) { a = 100; // เปลี่ยนแค่สำเนาที่อยู่ในฟังก์ชัน } int main() { int x = 10; modifyValue(x); cout << "x after modification: " << x << endl; // x ยังคงเป็น 10 return 0; }
x after modification: 10
🔗Pass by Reference
Pass by Reference 💻 C++
void modifyReference(int &a) { // มีเครื่องหมาย & a = 100; // เปลี่ยนตัวแปรต้นฉบับที่ชื่อ a อ้างอิงถึง } int main() { int x = 10; modifyReference(x); cout << "x after modification: " << x << endl; // x เปลี่ยนเป็น 100 return 0; }
x after modification: 100

💡 เคล็ดลับสำหรับค่าย: การส่งผ่านแบบอ้างอิง (&) มีประโยชน์มากเมื่อคุณต้องการให้ฟังก์ชันของคุณ แก้ไขค่าตัวแปร มากกว่าหนึ่งตัวพร้อมกัน เช่น การทำฟังก์ชัน Swap ค่าตัวเลข 2 ตัว

5. การประกาศ (Declaration) และการนิยาม (Definition)

📋การแยกประกาศและนิยาม

ใน C++ บางครั้งเราต้อง ประกาศ (Declare) ฟังก์ชันไว้ล่วงหน้าก่อน main() เพื่อให้ main() รู้จักฟังก์ชันนั้น ก่อนที่จะ นิยาม (Define) รายละเอียดของฟังก์ชันไว้ข้างล่าง

การประกาศ (Declaration / Prototype) ไว้ด้านบน
main() รู้จัก multiply() แล้ว
การนิยาม (Definition) ไว้ด้านล่าง

📐ตัวอย่าง: การแยกประกาศและนิยาม

Declaration and Definition 💻 C++
// 1. การประกาศ (Declaration / Prototype) ไว้ด้านบน int multiply(int a, int b); int main() { int result = multiply(5, 6); // main() รู้จัก multiply() แล้ว cout << "Result: " << result << endl; return 0; } // 2. การนิยาม (Definition) ไว้ด้านล่าง int multiply(int a, int b) { return a * b; }
Result: 30

📝 หมายเหตุ: หากนิยามฟังก์ชันทั้งหมดไว้ก่อน main() ก็ไม่จำเป็นต้องประกาศ Prototype

📋สรุปการปฏิบัติ (Quick Check)

  • ใช้ฟังก์ชัน void เมื่อต้องการให้ฟังก์ชันทำงาน แต่ไม่ต้องการผลลัพธ์ตัวเลขหรือค่าใด ๆ กลับมา
  • ใช้ฟังก์ชัน Non-void (เช่น int, bool) เมื่อต้องการให้ฟังก์ชันคำนวณและ ส่งผลลัพธ์กลับ มา
  • ใช้ Pass by Reference (&) เมื่อต้องการให้ฟังก์ชัน แก้ไขค่าของตัวแปรต้นฉบับ ที่ส่งเข้ามา

🏋️ โจทย์ฝึกหัด

🎯 โจทย์: ฟังก์ชันตรวจสอบเลขคู่

จงเขียนฟังก์ชันชื่อ isEven(int number) ที่รับตัวเลขจำนวนเต็มมา 1 ตัว แล้ว ส่งค่ากลับเป็น bool (True/False) เพื่อบอกว่าตัวเลขนั้นเป็นจำนวนคู่หรือไม่

💡 คำใบ้:

  • ใช้ตัวดำเนินการ % (modulo) เพื่อหาเศษจากการหาร
  • ถ้าหาร 2 แล้วเศษเป็น 0 แสดงว่าเป็นเลขคู่
  • ส่งค่ากลับเป็น true หรือ false
